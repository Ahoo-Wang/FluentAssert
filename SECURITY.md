# Security Policy

## Supported versions

Only the latest minor release line receives fixes.

| Version | Supported |
|---------|-----------|
| 1.2.x   | ✅        |
| < 1.2   | ❌        |

## Reporting a vulnerability

Please **do not** open a public issue. Report privately via
[GitHub Security Advisories](https://github.com/Ahoo-Wang/FluentAssert/security/advisories/new).
You should receive a response within 7 days. FluentAssert is a test-scope library that delegates to
AssertJ; vulnerabilities in AssertJ itself should be reported to the
[AssertJ project](https://github.com/assertj/assertj/security).
